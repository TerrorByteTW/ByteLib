# SQLite API

<secondary-label ref="wip"/>

ByteLib comes with an extremely opinionated yet extensible SQLite wrapper, abstracting away so much boilerplate it'd
make your head spin! The SQLite API was designed to look and feel like an ORM without taking away the power of raw SQL.
All examples in here will be from the [DimensionPause](https://github.com/TerrorByteTW/DimensionPause) plugin.
